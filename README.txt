# Sitharaputhiri Website

Welcome to the Sitharaputhiri Mela Stall website project! 🌸

## Setup Instructions

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Folder Structure

```
src/
├── assets/          # Place your images and music here
├── components/      # React components for each section
├── styles/          # Global styles
├── App.tsx          # Main application component
└── main.tsx         # Entry point
```

## Customization

-   **Images**: Replace the placeholder images in `src/components/Gallery.tsx`, `src/components/Team.tsx`, and `src/components/Preorder.tsx` with your actual files.
-   **Music**: Place `sitharaputhiri.mp3` in `public/assets/music/` or update the path in `src/components/MusicPlayer.tsx`.
-   **Content**: Edit the text in the respective component files.

Enjoy building your dream stall! ✨
